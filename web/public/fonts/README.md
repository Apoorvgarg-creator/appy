# Inter font assets

Unmodified Inter Regular, Medium and SemiBold WOFF2 fonts, originally by the Inter Project Authors. Bundled locally under the [SIL Open Font License](LICENSE.txt); the prototype makes no font requests to third-party servers.

Upstream: https://rsms.me/inter/ and https://github.com/rsms/inter. These static font files were copied from the local public Cube playground font assets.
